 # MERN Backend Roadmap (Phase Wise Table Format)

| Phase | Name | Goal | Main Topics | Projects |
|---|---|---|---|---|
| Phase 0 | Development Environment Setup | Setup backend development environment | Homebrew, Node.js, npm, VS Code, Git, MongoDB, Compass, Postman | First Node.js App |
| Phase 1 | JavaScript Fundamentals | Learn JavaScript for backend | Variables, Functions, Arrays, Objects, Async/Await, ES6+ | Calculator, Todo Logic |
| Phase 2 | Node.js Core | Understand backend runtime | Event Loop, npm, Modules, File System, HTTP Server | File Reader, CLI App |
| Phase 3 | Express.js Backend | Build REST APIs | Express, Routes, Middleware, REST APIs | Todo API, Notes API |
| Phase 4 | MongoDB + Mongoose | Learn database integration | CRUD, Schema, Models, Validation, Populate | Task Management API |
| Phase 5 | Authentication & Security | Build secure backend systems | JWT, bcrypt, Auth, Security, RBAC | Login/Auth Backend |
| Phase 6 | Advanced Backend Architecture | Write scalable backend code | MVC, Services, Repositories, Validation, Logging | Ecommerce Backend |
| Phase 7 | TypeScript Backend | Write professional backend code | Types, Interfaces, DTOs, Generics | Convert Backend to TS |
| Phase 8 | Redis & Caching | Improve backend performance | Redis, Cache, Sessions, OTP Storage | OTP System |
| Phase 9 | Docker & Deployment | Deploy backend professionally | Docker, PM2, Nginx, AWS, Render | Deploy Backend |
| Phase 10 | WebSockets & Realtime | Build realtime systems | Socket.IO, Events, Rooms | Chat App |
| Phase 11 | React Frontend Basics | Learn frontend integration | Components, Hooks, API Calls | Frontend Integration |
| Phase 12 | Full MERN Projects | Build production-level apps | Fullstack Architecture | Ecommerce, SaaS, Chat App |

## Commands Learned

| Purpose | Command |
|---|---|
| Check Node.js | `node -v` |
| Check npm | `npm -v` |
| Check Git | `git --version` |
| Start MongoDB | `brew services start mongodb/brew/mongodb-community` |
| Stop MongoDB | `brew services stop mongodb/brew/mongodb-community` |
| Restart MongoDB | `brew services restart mongodb/brew/mongodb-community` |
| Check Services | `brew services list` |
| Open Mongo Shell | `mongosh` |
