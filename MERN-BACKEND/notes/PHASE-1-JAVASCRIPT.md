# Important Rules

## DO

- write code daily
- use console.log heavily
- debug yourself
- practice manually
- solve logic problems

## DON'T

- memorize syntax only
- skip async concepts
- jump to Express too early
- copy tutorials blindly

# Most Important Topics

Focus deeply on:

- functions
- arrays
- objects
- promises
- async/await

These are used daily in backend development.
